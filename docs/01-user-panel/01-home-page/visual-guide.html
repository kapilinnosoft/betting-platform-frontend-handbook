Banner API

02

Popular matches and fixtures

One common Home capability, using the source's fixture APIs: active fixture rows refresh at 2 s; popular event cards use /events/popular plus fixture start times; the cricket table refreshes at 3 s.

rsplay:src/store/api/eventsApi.ts:298-315 (getEvents); rsplay:src/pages/Inplay/Hooks/useFixtureData.ts:55-57 (useFixtureData); vishnu7:src/store/api/sportsApi.ts:169-212 (getPopularEvents, getMatchesGroupedByCompetition); vishnu7:src/hooks/usePopularEvents.ts:4-12 (usePopularEvents); vishnu7:src/hooks/useGroupedFixtures.ts:20-30 (useGroupedFixtures)
FIXTURES
03

Fixture counts

GET /fixture/counts feeds the Home header every 2 s in rsplay. The vishnu7 Header instead queries user info and wallets; no fixture-count query is mounted there.

rsplay:src/store/api/eventsApi.ts:291-297 (getFixtureCounts); rsplay:src/components/Header.tsx:67-69 (Header); vishnu7:src/components/Header.tsx:46-48 (Header, no count query)
RSPLAY ONLY
04

Casino games and promotions

Home casino content is present across the implementations, with different endpoints and layouts: a card-game list, home games, provider games, and static promotions.
